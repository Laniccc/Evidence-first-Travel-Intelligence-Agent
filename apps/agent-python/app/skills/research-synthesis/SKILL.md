# Research Synthesis Skill

Use this skill when composing the final research report from extracted evidence claims.

## Report Structure

Every research report must include:

1. **Title** — Concise, answers the user's question.
2. **Summary** — 3-5 sentence executive summary of findings (50-200 words).
3. **Findings sections** — Organized by theme, not by source. Each section:
   - Has a clear heading
   - Synthesizes claims from multiple sources
   - Cites sources inline with [N] notation
   - Avoids simply listing sources one by one
4. **Citations** — Numbered list, each with: title, URL, tier.
5. **Limitations** — Honest assessment of evidence gaps, source quality issues, unanswered questions.

## Composition Rules

- ONLY state facts that appear in the provided evidence claims. Do not invent statistics, numerical data, or predictions.
- Every substantive claim must map to at least one citation [N].
- When evidence from different sources agrees, note the corroboration. When sources disagree, note the contradiction.
- Prefer Tier 1-2 sources for core claims. Mark Tier 3-4 sourced claims as tentative.
- When evidence is insufficient to fully answer the question, state this clearly in limitations rather than padding the report.
- Do not structure the report as "Source 1 says X, Source 2 says Y" — synthesize across sources.

## Quality Gates (Self-Check Before Delivery)

- [ ] Summary is substantive (50+ words)
- [ ] At least 3 citations with valid URLs
- [ ] Core claims cite Tier 1-2 sources where available
- [ ] Limitations section is present and honest
- [ ] No invented data or unsupported statistics
- [ ] Content is organized by theme, not by source

## Word Count Target

Aim for 200-500 words for the main findings. If evidence is thin, write a shorter honest report rather than padding.
